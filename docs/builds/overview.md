# Build Directory Structure

Each build directory (`builds/<name>/`) contains all configuration and static data for a specific pathogen/analysis. The source tree is never modified at runtime.

## Build File Layout

```
builds/<name>/
  config.yaml                 # Pipeline config (data source, parameters, QC thresholds, etc.)
  subsample.yaml              # Subsampling strategy (stratification, sequence counts)
  auspice_config.json         # Auspice display config (colorings, filters, panels)
  reference.gb                # Reference genome (GenBank format)
  clades.tsv                  # Clade definitions (mutation-based branch labels)
  cache_coordinates.tsv       # (Optional) Pre-computed geographic coordinates
  keep.txt                    # (Optional) Strain IDs to always include
  ignore.txt                  # (Optional) Strain IDs to always exclude
  masks/
    reference_terminal.bed    # (Optional) Terminal masking regions (BED format)
```

## Key Files

### config.yaml

Complete pipeline parameters. See [Configuration Reference](../configuration.md).

**Minimal example**:
```yaml
data_source: ncbi
region_source: country

files:
  reference: "reference.gb"
  reference_name: "NC_001802.1"
  clades: "clades.tsv"

parameters:
  mask_5prime: 50
  mask_3prime: 100
  ufboot: 1000
  model: "MFP"

ncbi:
  taxid: 11292
  genome_size: 10000
  min_length: 8000
  max_length: 12000
  email: ""

viralqc:
  expected_virus: "rubella"
  expected_segment: "genome"
  mode: "run"

qc:
  genome_quality: [A, B]
  min_coverage: 0.70
```

### subsample.yaml

Defines how sequences are selected for phylogenetics. See [Subsampling Reference](../subsampling.md).

**Example**:
```yaml
samples:
  group_by:
    - division
    - year
  sequences_per_group: 5

include:
  - strains: keep.txt

exclude:
  - strains: ignore.txt

defaults:
  max_date: 2025-12-31
```

### auspice_config.json

Auspice visualization configuration. See [Visualization](../visualization.md).

**Example**:
```json
{
  "title": "Dengue Virus 3 (Brazil)",
  "colorings": [
    {"key": "region", "title": "Region", "type": "categorical"},
    {"key": "serotype", "title": "Serotype", "type": "categorical"}
  ],
  "filters": ["region", "country"],
  "panels": ["tree", "map"]
}
```

### reference.gb

Reference genome in GenBank format. Required for:
- MAFFT alignment (template)
- `flexpipe-reference-mask` (UTR detection)
- `augur translate` (CDS coordinates)

**Obtain from**:
- NCBI RefSeq or GenBank
- Nextstrain builds
- Published references

### clades.tsv

Tab-separated table of clade definitions. Read by `augur clades`:

```
clade	gene	site	alt
Clade_I	E	417	K
Clade_I	E	439	K
Clade_II	E	417	R
Clade_II	NS1	127	V
```

**Empty file** (header only) is valid; sequences will simply have no clade assignments.

**Columns**:
- `clade` — clade name/label
- `gene` — gene/protein identifier (must match reference.gb features)
- `site` — 1-indexed position in gene/protein
- `alt` — alternative (derived) allele

### cache_coordinates.tsv

Pre-computed geographic coordinates to seed the workdir cache. Format:

```
name	latitude	longitude
Brazil	-14.2	-51.9
SP	-23.5	-46.6
RJ	-22.9	-43.2
```

Copied to `<workdir>/cache/` on first run. Optional; if absent, Nominatim API is used.

### keep.txt, ignore.txt

Newline-separated strain IDs:

**keep.txt** — Always include these strains (even if filtered by QC):
```
reference_strain
favorite_sequence_1
favorite_sequence_2
```

**ignore.txt** — Always exclude these strains (contaminants, artifacts):
```
contaminated_seq_1
wrong_organism_seq
duplicate_strain_old_version
```

### masks/reference_terminal.bed

(Optional) BED file specifying regions to mask:

```
NC_001802.1	0	100	5_prime_UTR
NC_001802.1	9900	10000	3_prime_UTR
NC_001802.1	5000	5100	polyA_tract
```

Referenced by `parameters.mask_sites_file` in config.yaml.

Generated by `flexpipe-reference-mask`; review manually before production use.

## Profiles: First-Pass vs Production

Two common configurations:

### First-Pass

Fast turnaround, suitable for exploration:

```yaml
parameters:
  ufboot: 0           # Disable UFBoot
  model: "JC"         # Simple model
  date_confidence: false
  traits_confidence: false
```

### Production

Higher quality, suitable for surveillance:

```yaml
parameters:
  ufboot: 1000        # High-confidence bootstraps
  model: "MFP"        # Model selection
  date_confidence: true
  traits_confidence: true
```

YFV (`builds/yfv-brazil/`) is production-tuned. Other builds default to first-pass; customize as needed.

## Path Resolution

File paths in `config.yaml` are resolved relative to the build directory:

```yaml
files:
  reference: "reference.gb"      # → builds/<name>/reference.gb
  clades: "clades.tsv"           # → builds/<name>/clades.tsv

parameters:
  mask_sites_file: "masks/reference_terminal.bed"  # → builds/<name>/masks/reference_terminal.bed
```

Absolute paths are left as-is.
