# Visualization

flexpipe outputs an [Auspice](https://docs.nextstrain.org/projects/auspice/en/latest/)-compatible JSON file that enables interactive phylogenetic visualization.

## Viewing Results

After a successful run, open the results:

```bash
auspice view --datasetDir <workdir>/auspice/
```

Then open `http://localhost:4000` in your browser.

## Auspice Configuration

The `auspice_config.json` file in your build directory controls visualization settings:

```json
{
  "title": "Yellow Fever Virus (Brazil)",
  "description": "Real-time tracking of YFV in Brazil",
  "colorings": [
    {
      "key": "region",
      "title": "Region",
      "type": "categorical"
    },
    {
      "key": "country",
      "title": "Country",
      "type": "categorical"
    },
    {
      "key": "clade_truncated",
      "title": "Genotype",
      "type": "categorical"
    },
    {
      "key": "num_date",
      "title": "Date",
      "type": "continuous"
    }
  ],
  "filters": [
    "region",
    "country",
    "division",
    "clade_truncated"
  ],
  "panels": [
    "tree",
    "map",
    "entropy",
    "frequencies"
  ],
  "geo_resolutions": [
    {
      "key": "country",
      "demes": {
        "Brazil": {"latitude": -14.2, "longitude": -51.9}
      }
    }
  ]
}
```

### Colorings

Define metadata fields available for coloring the tree:

```json
"colorings": [
  {
    "key": "region",
    "title": "Region",
    "type": "categorical"
  }
]
```

| Property | Type | Purpose |
|----------|------|---------|
| `key` | string | Metadata column name |
| `title` | string | Display name in Auspice |
| `type` | string | `categorical` or `continuous` |

**Categorical** coloring uses the `colour_scheme.tsv` generated by `flexpipe-colours`.

**Continuous** coloring (e.g., collection date via `num_date`) uses a gradient.

### Filters

Metadata fields available as interactive dropdown filters:

```json
"filters": ["region", "country", "division"]
```

Users can interactively select/deselect values to highlight or hide branches.

### Panels

Control which visualization panels appear:

```json
"panels": ["tree", "map", "entropy", "frequencies"]
```

Available panels:
- `tree` — phylogenetic tree
- `map` — geographic map (requires geo_resolutions)
- `entropy` — mutation rate
- `frequencies` — allele frequency trajectories

### Geo Resolutions

Define geographic hierarchy and coordinates:

```json
"geo_resolutions": [
  {
    "key": "country",
    "demes": {
      "Brazil": {"latitude": -14.2, "longitude": -51.9},
      "Argentina": {"latitude": -34.6, "longitude": -58.4}
    }
  },
  {
    "key": "division",
    "demes": {
      "SP": {"latitude": -23.5, "longitude": -46.6},
      "RJ": {"latitude": -22.9, "longitude": -43.2}
    }
  }
]
```

The `flexpipe-coordinates` command auto-generates these from metadata.

## Color Hierarchy

The `colours` config key determines the color hierarchy:

```yaml
colours:
  - continent
  - country
  - division
  - location
```

**Top level** (`continent`): Fixed hues from `flexpipe/data/colors/region_hues.tsv` or deterministic hash.

**Sub-levels** (`country`, `division`, `location`): Shades derived from the parent hue family.

This ensures consistent, perceptually distinct colors across the visualization.

## Trait Colors

Clade and geographic trait colors are inferred from the phylogenetic tree via `augur traits`. Each trait gets its own color column.

Example metadata:
```
strain	country	division	clade_truncated
SEQ_001	Brazil	SP	I
SEQ_002	Brazil	RJ	II
```

Auspice uses the color scheme to assign consistent colors to each unique value.

## Custom Colors

For fine-grained control, manually edit `auspice_config.json`:

```json
"colorings": [
  {
    "key": "clade_truncated",
    "title": "Genotype",
    "type": "categorical",
    "scale": [
      ["I", "#1f77b4"],
      ["II", "#ff7f0e"],
      ["III", "#2ca02c"]
    ]
  }
]
```

Each value maps to a hex color.

## Interactive Features

Auspice provides:
- **Tree navigation**: zoom, pan, toggle branches
- **Temporal slider**: filter by collection date
- **Geographic map**: click locations to highlight sequences
- **Metadata search**: find strains by name or ID
- **Export**: download subtrees or metadata as TSV/JSON

## Building Custom Configs

1. Start with a template build's `auspice_config.json`
2. Edit metadata field names to match your curation output
3. Add/remove colorings, filters, panels as needed
4. Test with `auspice view --datasetDir <workdir>/auspice/`

See [Auspice documentation](https://docs.nextstrain.org/projects/auspice/en/latest/customization.html) for all configuration options.
